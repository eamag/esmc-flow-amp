# Recorded results

Every number in the writeup is in one of these files.

| File | What it is | Produced by |
| --- | --- | --- |
| `PHASE1_DEEP3.md` | Phase 1 harness, n = 1,000, seed 42: this library and top-100 against our earlier diffusion pair (DiffTabPFN) | `esmc_flow_amp.phase1_harness`, run on both pairs together |
| `COMPARE_val4.md` | Ten paired draws from the held-out DBAASP half: FBD, MMD, Precision, Recall, Conformity, Diversity, win rates | the research repository's `scratch/run1/compare.py`; it needs the earlier pair's files, so it is not part of this single-path repository |
| `validate_rankers.md` | TabPFN against AMPredictor as rankers on 752 held-out measured MICs | the research repository's `scratch/run1/validate_rankers.py` |
| `coverage_results.csv` | DBAASP clusters covered by each library at identities 0.5-0.8 | the research repository's coverage script |

The research repository is `eamag/ampch` (private at the time of writing).
These files are records, not regenerated by `run_pipeline.sh`.
